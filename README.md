**Global SCM for Seafood**

**Overview**

The Global Seafood Supply Chain Management System is a full-stack web application developed to improve transparency, monitoring, and efficiency in seafood distribution and supply chain operations. The system manages seafood products, suppliers, inventory, orders, and shipment tracking through different stakeholder modules.

**Features**
1.User and Admin Registration form
2.Dashboard
3.Inventory Management
4.Order Management
5.AI module

**Stakeholder Modules**
Admin
Supplier 
Wholesaler
Distributor
Retailor

**Technologies Used**

**Frontend**
React.js
Tailwind CSS


**Backend**
Node.js
Express.js

**Database**
MySQL

**Future Enhancements**
AI-based seafood demand prediction
Blockchain-based seafood traceability
Real-time IoT monitoring for storage temperature
Mobile application support
Payment gateway integration
